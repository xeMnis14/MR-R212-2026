# Rapport — [TP4]

## Points clés

### 1. [async + await]

async est obligé d'être écrit devant une fonction où l'on utilise await. Await dit juste d'attendre que l'action soit fini avant de passer à la suivante.

### 2. [fetch]

fetch va chercher des fichiers que ce soit une API ou un JSON et va retourner un objet.
